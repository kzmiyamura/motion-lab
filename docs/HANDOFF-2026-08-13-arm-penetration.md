### デプロイの注意

GitHub 連携の自動ビルドは遅い（10分以上待っても出ないことがあった）。急ぐときは

```
npm run build && npx wrangler pages deploy dist --project-name motion-lab --branch main
```

**本番に出たかの確認で `curl -o /dev/null -w %{http_code}` を使ってはいけない。**
Cloudflare Pages は存在しないパスに index.html を 200 で返すので、200 は何の証明にもならない。
正しくは index の中身からチャンク名を取り出して比較する:

```
curl -s https://motion-lab-apa.pages.dev/ | grep -o 'assets/index-[A-Za-z0-9_-]*\.js'
curl -s https://motion-lab-apa.pages.dev/assets/index-XXXX.js | grep -o 'SalsaStage3D-[A-Za-z0-9_-]*\.js'
```

これを手元の `dist/assets/` の名前と突き合わせる。ユーザーには**ハードリロード**を頼むこと
（PWA の SW が古い版を掴む）。
