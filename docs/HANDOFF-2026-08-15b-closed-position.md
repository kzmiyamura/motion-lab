## 1. クローズドポジション

ボタン「🤝 クローズドで組む / 🙌 クローズドを解除」。ベーシック・CBL のどちらでも効く。
再生位置を保ったままクリップを組み直すので、同じ拍で見比べられる。

### 正解として実装した形（ユーザーの説明どおり）

- 2人は正対し、上半身が触れるくらい近い
- **リーダー右手** → フォロワーの**左肩甲骨**（肩より 10cm 下・肘は下ろす）
- **フォロワー** → **ニュートラルポジション**（肘を下ろし、上腕を体側から離して**脇を開ける**）
  - ユーザー指示: 「女性は基本的に手をニュートラルにしておけば脇がひらくから、
    男性はクローズドに入るために背中に手を回しやすい」
  - **相手の肩を掴みに行かせない**。掴みに行かせると腕が必ず上がる（下記）
- **リーダー左手 × フォロワー右手**は片手ホールドのときと同じ

### 「少し手を挙げる」バグの正体（寸法の話・推測ではない）

- 腕の長さは **0.52m**（`ARM_REACH` = (0.28+0.27)×0.95）
- 男の右肩から女の背中までは「腰の間隔 + 胴半径」。腰の間隔 0.40m のとき **0.61m 先**＝届かない
- 届かない目標は腕が伸び切って水平に突き出す → これが「手を挙げている」の正体。
  肘が曲がる余地がないので肘も下がらない
- **対処**: 腰の間隔を **0.30m**（`CLOSED_HALF_GAP = 0.15`）に詰め、背中の的を肩の 10cm 下、
  胴からの浮きを 1cm に。これで 0.48m となり腕に収まる

**教訓**: 腕が変な形になったら、まず「その的に手が届くのか」を長さで確かめる。

### 距離の詰め方

- **ベーシック**: 腰の間隔 0.70m → 0.30m。腰から見た足の位置は 1 ミリも変えない（テストで固定）
- **CBL**: 組んでいる 0〜8 拍だけ詰め、**通り抜け（9〜15拍）は元の間隔に戻す**（`closedAmt()`）。
  詰めたままでは女が男を追い越せない。**男は 1 ミリも動かさない**（焼き込んだ足の振付を触らない）
  ので、寄るのは女だけ
- CBL の腕も同じ区切りで、`prep`/`pass`/`close` の間は組み手を離す

### 実装の在り処

- `MocapFigure.tsx`: `ArmHandState` に `closed_back` / `closed_shoulder` を追加
- `scriptedClip.ts`: `CLOSED_HANDS`・`CLOSED_HALF_GAP`・`closedAmt()`、
  `buildScriptedBasic(timing, closed)` / `buildScriptedCBL(timing, closed)`
- `CoupleFigure.tsx`: レイヤー3.6（`closedL` / `closedF`）。`NEUTRAL_HAND = [0.26, -0.14, 0.22]`
- `SalsaStage3D.tsx`: `closed` state と `toggleClosed()`

## 2. 入れ替わりで腕が自分の体に埋まる（修正済み・未確認）

`prep`/`pass`/`close` の間だけ自胴を太く見る（`TORSO_R_SELF` 0.13 → `TORSO_R_SELF_PASS` **0.165**）。
併せて、肩→手の**線**だけでなく**手そのもの**も自胴の外へ押し出す。
体が回りながらすれ違うと、線は胴を横切らないのに手だけが脇腹へ入る姿勢が作れてしまうため。

## 3. CBL On2 の女の足（新規・未確認）

これまで女の足は手続き生成のまま（前回メモの「女は次の段階」）。**On2 だけ**焼き込んだ。

- `cblLandings(keys, timing, mirror)` に `mirror` を追加。女は男の鏡なので
  **足の左右を入れ替え、前後（fwd）を反転**する。踏み出し量はベーシック On2 の値をそのまま使う
- 踵も鏡（4 = 右、8 = 左）
- クローズドで腰を寄せたぶんは足も一緒に動かす（`fFoot()`）。動かさないと脚が引き伸ばされる
- **On1 の女は据え置き**（合格済みの見た目を触らない）。テストで固定してある

実測（拍10→14 の同じ足の移動距離）: 男 0.388 / 女 0.399 で一致。
CBL は2人とも移動しているので、値そのものはベーシックの 0.70 にはならない。

## 4. その場で踏む足の浮き（未確認）

ユーザー指摘「その場で踏む足がわかりにくい。もう少し上げて」に対し、**別経路なので定数は2つ**:

| 対象 | 定数 | 変更 | 浮き |
|---|---|---|---|
| On1 ベーシック（2・6 の踏み直し） | `TAP_LIFT` | 0.04 → **0.075** | 7.5cm |
| On2 ベーシック（3・7 の靴1/4） | `FLOW_LIFT_MIN` | 新規 **0.60** | 約 2.8cm → **約 4.2cm** |
| CBL On2（カウント7） | `CBL_ON2_LIFT_MIN[7]` | 0.75（前回のまま） | — |

`TAP_LIFT` は CBL On1 のその場踏みにも効く（同じ非 flow 経路）。

## 5. 色のカスタマイズ

操作バーに **👞 リーダーの靴 / 👠 フォロワーの靴 / 🎨 背景** のカラーピッカーと
「↩ 色を既定に戻す」を追加（既定値は従来どおり）。
「リーダーの靴が背景と同化して見えない」というユーザー指摘への対応。
床は背景色から作る（白に 8% 寄せる）ので、背景を明るくしても床だけ黒く残らない。

## 6. 顔アバターの頭（未確認）

「顔だけが青／ピンクの頭にこびりついて気持ち悪い」への対応。
後頭部の球を役割の色で塗るのをやめ、**写真そのものから色を拾う**ようにした（`AvatarHeads.tsx`）。

- 髪 = 画像上端の帯（頭のまわりの切り出しなのでほぼ髪か帽子）／肌 = 両頬
- どちらも明るさの上下 20% を捨てて平均（影・テカリに引っ張られない。`regionAverage()`）
- 頭は「球（肌色）＋後ろへ倒した髪のキャップ（髪色）」の2枚。髪は顔メッシュ（z=+0.075）より
  前へ出ない半径なので顔は隠れない
- 役割の色は服に残るので、青＝リーダー／ピンク＝フォロワーの見分けは変わらない
