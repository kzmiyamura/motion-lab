## 1. ニュートラルポジション（フォロワーの構え）

### 何の話か

技をしていないときにフォロワーの手が置かれる場所。リーダーとつながって
合図を受け取る場所であり、**脇が開くから**リーダーの手が背中へ回れる。

### 確定した形（ユーザー確認済み）

**手は体の正面・胸の高さ。肘は曲げて下と外へ張る。**

```
手  : 正面 30cm前 / 横 13cm / 高さ 腰から 30cm（肩は 40cm ＝ 肩より 10cm 下）
肘  : 肩の真下から外へ 7.3cm、肩より 25cm 下
肘角: 109°   肩→手 32.1cm（腕 52.2cm・伸び切らない）
```

`src/engine/armPose.ts` の `NEUTRAL_HAND = [0.13, -0.10, 0.30]`（胸郭ローカル [横, 肩からの高さ, 前]）。

### 一度作って却下された形（同じ失敗を繰り返さないために残す）

| 作ったもの | 実測 | 指摘 |
|---|---|---|
| 手を**真横**へ張り出す `[0.26, -0.14, 0.22]` | 肘角 121°・脇 13.4cm | 「ニュートラルポジションがわかってない」 |
| 手を**へその高さ**へ `[0.13, -0.24, 0.30]` | 手が腰から 16cm | 「今こしあたりにあるぞ」 |

高さだけ動かしたときの実測（他は据え置き）:

| 手の高さ（腰から） | 肘角 | 脇の空き | 肘の高さ |
|---|---|---|---|
| 16cm（へそ） | 90° | 7.3cm | 13.7cm |
| 24cm（みぞおち） | 102° | 7.5cm | 14.4cm |
| **30cm（胸）← 採用** | **109°** | **7.3cm** | **15.4cm** |
| 34cm（鎖骨寄り） | 111° | 7.1cm | 16.6cm |

**脇の空きは高さをどう変えてもほぼ 7.3cm で変わらない。** 効くのは手の高さと肘角だけ。

### 実装

- `src/engine/armPose.ts`（新規）: `NEUTRAL_HAND` と `armSolve()`。
  `armSolve()` は `solve2Bone`/`armPole` と**同じ式**の純関数で、肩ローカルの的から
  **肘の位置・肘角・脇の空き・肩から手までの距離**を返す。
  → 構えの定数を動かしたら、描画を見なくても数字で確かめられる（今回の再発防止の本体）
- `CoupleFigure.tsx` は `NEUTRAL_HAND` をそこから読むだけ。定義は1箇所
- **フォロワーの空き手は常にニュートラル**にした（レイヤー4 の `d === 1` 分岐）。
  クローズド中（レイヤー3.6）と同じ的なので、組む／解くで手が飛ばない
- リーダーの空き手は従来どおり（触っていない）
