## 残っている問題（直していない）

1. **CBL のパス中、つないだ手が約 34cm 離れる**（CBL On1 の t≈3.8〜5.1s）。リーダーの左手は
   `ARM_ACROSS`（−0.20）より体を横切れないので、2 人の腕の届く範囲が重ならない。
   `ARM_ACROSS` を緩めるか、パス中だけ手を離すかの判断が要る
2. **CBL On2 の armTimeline**: 最初の `closed` 区間が、前の周の末尾（`buildSegments` のずらし）に
   かぶる。フォロワーがまだパス中なのにリーダーがクローズドの向き・ホールドになる（`scriptedClip.ts` 側）
3. ループの継ぎ目で 2 人の距離の下限が違う（0.42 / 0.58）
4. 残った「腕→自分」の大半は、リーダーのつないだ側の上腕が自分の胴に約 5cm 入るもの。
   ホールドのポールに入れている「相手の逆側へ肘を出す」項（−0.7）が原因。対策2 の振りでは
   上腕の付け根 35% を除外しているので取り切れない

## 測り方・更新の仕方

- `npx vitest run src/__tests__/rigQuality.test.ts` — 悪化（割合 0.2pt・0.1cm・0.2° を超える）で落ちる
- `UPDATE_RIG=arms` — 指標と腕のスナップショットを取り直す（意図した改善のとき）
- `UPDATE_RIG=all` — 体のスナップショットも取り直す（腰・脚を意図して変えたとき）
- `RIG_REPORT=path` — 全指標・最悪フレーム・中立の手の平均を JSON に書く
