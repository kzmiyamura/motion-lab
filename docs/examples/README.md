# フォルダの解析指示書の雛形

フォルダに `preset: general` の指示書を置き、動画をそのフォルダに移すと、指示書どおりの解析が走ってレポートが付く。
ここは、その指示書の雛形集。設計は `docs/folder-analysis-detailed-design.md` の §13。

## 雛形の一覧

| ファイル | 趣味・場面 | 撮り方 |
|---|---|---|
| `folder-spec-softball-batting.md` | ソフトボールのバッティング | 打者 1 人、横または斜め前 |
| `folder-spec-golf-swing.md` | ゴルフのスイング | 1 人、横（飛球線の後ろ）または正面 |
| `folder-spec-tennis-stroke.md` | テニスのストローク・サーブ | 1 人、ラリーの中の複数回 |
| `folder-spec-solo-dance.md` | ソロのダンスの振り付け | 1 人、音楽あり（拍を使う） |
| `folder-spec-kids-event.md` | 子どもの運動会・発表会 | 大勢の中の 1 人を追う |
| `folder-spec-workout-form.md` | 筋トレ・ストレッチのフォーム | 1 人、同じ動きの繰り返し、真横が望ましい |

構成はどれも同じ: 目的 / 見る観点 / 判断のヒント（general の計測のどれをどう使うか）/ レポートの形式 / 注意。

## 新しい趣味のフォルダの作り方

1. フォルダを作る
2. 一番近い雛形を指示書の編集画面に貼り、自分の趣味に合わせて書き換える（先頭の `preset: general` は残す）
3. 動画をフォルダに移す。解析ジョブが積まれ、終わるとレポートが付く
4. レポートを読み、足りないところを指示書に足して再解析する。満足するまで 3〜4 を繰り返す

## 指示書を育てるコツ

- 結果を見て直す: 見てほしかった観点が出ていなければ「見る観点」に足す。根拠が曖昧なら「判断のヒント」に、どの計測をどう使うかを書き足す
- 計測で分からないことは、決めつけさせずに「画像で確かめる」と書く（利き手、撮影の向き、種目の種類など）
- general の計測でできることとできないことを、「注意」に正直に書く。ボールや道具は追跡しない、骨格は 2D で約 10fps（一瞬の動きや細かい指先は捉えにくい）、など
- 追う人が決まっているなら、位置・服装など画面で分かる手がかりを書く。`mainPersons` の id は入れ替わるので当てにしすぎない
- 出してほしい形は具体的に書く（「良い点は最大 3 つ、時刻つき」など）。数値は、確かめずに書かせない
- 一度に直しすぎない。1 回の再解析で足すのは 1〜2 項目にして、効いたかを見る
- 指示書で足りないとき（専用の計測が要るとき）は、設計 §13.1 のとおり、general をもとに専用の preset を作る
