# ソフトボールのバッティング動画の解析

## 目的
打者 1 人のスイングを横または斜め前から撮った動画で、フォームの崩れとタイミングの良し悪しを、
本人が次の練習で直せる形で伝える。

## 見る観点
- 構え: 足幅・膝の曲がり・頭の位置が安定しているか。スイング前に体が上下左右に揺れていないか
- 始動（ステップ〜踏み込み）: 前足を踏み出すとき、頭と上半身が前に突っ込んでいないか。腰と肩の開きが同時になっていないか
- 回転: 腰が先に回り、肩・腕が遅れてついてくるか。肩と腰が同時に回っている（手打ち）場合は指摘する
- インパクト付近: 頭がボール方向に残っているか。両肘の曲がり、手首の位置
- フォロースルー: 最後まで振り切っているか。体が一方に流れていないか
- 複数回のスイングがあるときは、スイングごとに上を見て、ばらつきも書く

## 判断のヒント
- `summary.motion.peaks` の山が各スイングのだいたいの瞬間。山の前後 0.5 秒のキーフレームを必ず見る
- キーフレームが足りないスイングは、時刻を書いたうえで「画像が無く判断できない」とする
- 映っている人が複数いるときは、画面の中で一番大きく映っている人を打者とみなす。
  id は途中で入れ替わるので、id ではなく画面上の位置と大きさで同じ人を追う
- 骨格の左右は本人の左右。右打ちか左打ちかは画像で先に確かめる
- 肩と腰の線の傾き（keypoint 5/6 と 11/12 の座標）で回転の先行・遅れを数値で補強してよい。ただし横から見ると潰れるので、画像と矛盾したら画像を優先する

## レポートの形式
1. 概要（打者の特徴を 2〜3 文）
2. 良い点（最大 3 つ。時刻と根拠つき）
3. 直す点（最大 3 つ。優先度の高い順。時刻・何が起きているか・次の練習で意識すること）
4. スイングごとのメモ（スイングが複数ある場合のみ。`m:ss` つきの短い箇条書き）
5. 判断できなかったこと

`result.json` の `findings` は「良い点」「直す点」を 1 件ずつ入れ、`title` の頭に `[良]` か `[直]` を付ける。

## 注意
- 打球の飛び・当たりの良さは、ボールが映っていなければ書かない
- 数値の目安（角度など）を、画像や計測で確かめずに書かない
- 道具・ユニフォーム・撮影環境の話はしない
