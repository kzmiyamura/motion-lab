### 正解を作っていて気づいた解析の弱点

- **右回りが左回りと出る（向きの誤りは全部この向き）**: 向きを外した 6 件は全て「正解は右、解析は左」だった（bb0efcb9 で 4 件、img1884 と screenrec で 1 件ずつ）。
  左回りを右と出したものは 1 件も無い。bb0efcb9 の 3 件（11.4・23.3・35.4）は 0.05 秒刻みで見直し、右回りで間違いない。
  女性が背中を向けたときに COCO の左右の肩が入れ替わって付く、などの片寄った原因がありそう。
- **男のターンをほぼ拾えていない**: bb0efcb9 では男が 6 回はっきり回っている（ほとんど左回り、0.5〜0.8 秒で 1 回転）が、検出は 0。
  随伴回転フィルタ（CBL や女性のターンから ±1.2 秒以内の男のターンを捨てる）が、本物の男のターンまで消しているかもしれない。
- **回転数を少なく出す**: CBL の通過から続けて回るもの（通過の½込みで 1½〜2½）を 1 と出すことが多い（2fda2815 の 5.9 / 9.2、bb0efcb9 の 8.5）。
- **CBL の通過に続くターンの取りこぼし**: 2fda2815 の 11.2 / 13.8 / 19.2（頭上で手をつないだまま 1½〜2½ 回る）を 3 件とも見逃した。

## 次にやること（優先順）
