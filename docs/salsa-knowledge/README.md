- `server/src/claudeRunner.ts` が裁定のたびに `move-dictionary.md` と `on2-timing-and-terms.md` をジョブの作業ディレクトリの
  `knowledge/` に写す。裁定役は必要なときだけそれを Read する。
- `server/analysis/normalize_routine.py`（拍の位相・steps のひな形・回転数）と `src/engine/choreoSheet.ts`（凡例・回転の書き方）は、
  この資料の決まりに従っている。

## 反映済み（2026-10）

正解表は `server/analysis/ground_truth/1230b3d5.json`、評価は `eval_routine_grid.py` で行った。
数字は cbl / swap / cblRows / rowAgree / turn の順。

1. **On2 の拍の位相**: `SWAP_BEAT` を 7.0 から 4.25 に変えた。7.0 は On1 の「女性が 5 で通る」を写したもの。
   CV で取った左右の入れ替わりは、実際の通過より約 3 拍遅れる。
   - steps のひな形は ET2 に合わせた。男は 7-1 で開き、女性は 2 で通る。インサイドは 2-3-(4)-5、右ターンは 1 から（5-6-7 で準備）。
   - make_move_frames の補助ラベルも ET2 に合わせた。
   - 581ef6a2: .900/.903/.900/.879/.667 → **.967/.968/.897/.914/.667**。位相の平均カウントは 4.96 → 2.19。
   - 2f4b6919: .833/.839/.909/.807/.833 → .833/.839/.875/.786/.5。
2. **インサイド/アウトサイドは向きだけで決める**: 女性の左回り＝インサイド、右回り＝アウトサイド（on2-timing §3）。
   つなぐ手で逆にする旧ルールはやめた。文言は左回り/右回りを主にし、インサイド/アウトサイドは括弧で添える。
   581ef6a2 では向きの付いた女性のターン 24 行のうち **9 行が逆に戻った**。ほかに 1 行は名前が付いていなかったが、今回アウトサイドになった。
3. **回転数の目安への寄せ（`apply_rotation_prior`）**: CBL は ½、CBL＋ターンは 1½（2½）、その場は 1（2）、男は 1（2）。
   はっきり見えた証拠（conf ≥ 0.7）か、CV と ±¼ 以内で一致したときだけそのまま残す。
   回っていた拍数（最低 4 拍）を超える回転数は削る。`routine.rotationChecks` に記録する。
4. **テンポの範囲**: 無音のときの格子は 150〜250 BPM に収める。75〜125 BPM は倍にする。GT の数字は変わらない。
5. **入れ替わりの近くにあるその場ターンを CBL＋ターンに直す処理を両方向に広げた**: 右回りのときは `cbl_outside_turn` に直す。
   CBL の行から入れ替わりを奪う版も試したが、GT が下がったので戻した。
6. **ブレークステップの拍合わせを試した（出していない）**: 2 人の中点・各人・足首の 8 拍周期の位相の集中度を測った。
   2 本とも帰無分布の 95% 点以下だった（中点 |z| = 0.149、帰無 0.236。足首 ≈ 0.06、帰無 0.17）。この動画では使えない。
   ただし 2 人の距離のピークがカウント約 8.8（1 の直前）に来ており、男が 7-1 で開くことと矛盾しない。

## 次にやること（優先順）

1. **局所的な位相（区間ごとの格子）**: 正解の通過の拍が、動画の前半は約 2、後半は約 4 にずれていく。
   モントゥーノでテンポが上がるか、CV の遅れの周期に偏りがあるため。
   いまは格子が 1 本なので、581 の冒頭（カード 1・2）は約 1.5〜2 拍早く数えている。
   区間ごとに位相を当て直すか、緩い drift 項を入れる。効果は一番大きいはず。
2. **ターン区間だけ 20〜30 fps で取り直す**: 10 fps だと 1 回転が 6〜7 コマで、ダブルでは向きの折り返しが見えない。
   回る向き・回転数の精度を上げる。
3. **人物 ID の入れ替わりへの耐性**: 密着ですれ違う瞬間に第三者を拾うと、通る側・回る向きが反転する。
4. **コンガのスラップ（2・6）を音で拾う**: 音声がある動画で、On2 の 2 と 6 を直接合わせる手がかりにする。
5. **体の向きの角度（θ）を unwrap する**: 正面・横・背中の 4 値ではなく連続角で回転数を数える。
6. **インバージョン（シャインで男女の役割が入れ替わる等）を検出する**。
7. **振付シートの形式**: 時計の文字盤で向きを示し、各部品に「見えた / 推定」を出す。
8. **上手さの採点（5 軸。NYSC の配点を参考に）**: analyze_skill.py の指標を基準分布につなぐ。
9. **CoMPAS3D の語彙・誤りの分類を取り込む**。
10. **ブレークステップの拍合わせをやり直す**: ベーシックの多い動画、または高 fps の動画で。今回の 2 本はターン主体で信号が出なかった。
