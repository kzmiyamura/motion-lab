# サルサの技の文法（解析と3D再生の共通語彙）

サルサの技は無限に見えるが、やっていることは**数種類の部品の組み合わせと順番**にすぎない。
このファイルはその部品と、部品から技名を組み立てる規則、カメラ1台で見えないときの推定規則を定める。
解析（`server/prompts/runner-prompt.md` の `routine`）と3D再生（`src/engine/routineClip.ts`）は
この語彙で話す。出典の調査は流派差（⚠）も含めて本文末の「出典」にまとめた。

## 0. 大原則 — 左右は「男性の体」で言う、カメラでは言わない

- 女性が通る側・立っている側は**男性の体から見た左右・前後**で書く（男性の元の正面向きを基準にする）。
- 「画面の左右」「カメラの手前/奥」は**証拠**であって答えではない。
  例: 「カメラから見て女性が男性の後ろ（奥）を通った」は、男性が画面左を向いていれば**男性の右**、
  画面右を向いていれば**男性の左**を通ったことになる（下の 4.2）。
- 回転は**真上から見た向き**で書く。右回転 = 時計回り（CW）、左回転 = 反時計回り（CCW）。
  インサイド = 女性の左回転、アウトサイド = 女性の右回転（⚠ 教室によって腕の軌道で呼ぶ流儀もあるので、必ず左右回転を併記する）。

## 1. 状態（技と技の間で受け渡すもの）

技は「状態 → 状態」の変化として書く。状態は4つの量で決まる。

| 量 | 値 |
|---|---|
| 女性の位置（男性の体から見て） | 正面（スロットの向かい） / 右横 / 左横 / 真後ろ |
| 向きの関係 | 向かい合う / 同じ向き（並ぶ・シャドウ） / 背中合わせ |
| 手（ホールド） | なし / `LR`（男左×女右・基本の片手） / `RR`（握手） / `RL` / `LL` / 両手 / 交差（右が上・左が上） / クローズド / ハンマーロック / ラップ |
| スロットの端 | 女性が最初の端か反対の端か（CBL のたびに入れ替わる） |

## 2. 部品（プリミティブ）— これだけで全部書ける

1つの技 = 1×8（8カウント）または 2×8 の中で、次の部品がいくつ起きたか。

| 部品 | 中身 | 決める値 |
|---|---|---|
| **ステップ** | ベーシック（前後）・サイド・ガペア・シャイン | どれか |
| **パス（場所の入れ替え）** | 女性が男性の横を抜けてスロットの反対端へ | 通る側（男性の左 / 右）、戻るか（コパは行って戻る） |
| **ターン** | 誰かが体を回す | 誰（女性/男性/両方）・向き（右/左）・回数（½ 刻み）・その場か移動しながらか |
| **持ち替え** | 手が変わる | 何拍目に、誰のどの手がどの手に |
| **形** | ラップ・ハンマーロック・シャドウ・ディップなどの止める形 | 入る / ほどく |

カウントの原則（On1）: 女性が動く・回るのは **5-6-7**（ピボットは 5〜6）、準備（プレップ）は **1-2-3**（特に 3）。
男性が自分で回るのは 1-2-3。

**On2（Eddie Torres 式 = ET2。このアプリの基準）**: ブレークは 2 と 6（男は 2 で右足を後ろ・6 で左足を前）。
On1 を半小節ずらしただけにしない（`docs/salsa-knowledge/on2-timing-and-terms.md` §2・§5）:

- CBL: 男は 6 で前へブレークし **7-1 で左へ約 90° 開く**。女は 1-3 で横断し **2 で男の左を通り**、3 あたりで ½
- CBL＋インサイド（左 1½）: **2 から回り始め 2-3-(4)-5**、5 で着地。アウトサイド（右 1½）も 2 から
- その場の右ターン: 前の **5-6-7 で準備**し、**1（早ければ 8）から回る**。左ターンは 2 から回り 5 で着地
- コパ: 2 で男の前へ入り 3 で止まり、4-5 で戻る。男自身のターンは 5-6-7
- 1 回転 ≈ 2 拍。回転数の目安: CBL ½・CBL＋ターン 1½・その場 1・ダブル 2（CBL 付きは 2½）

## 3. 技名は部品の組み合わせ（辞書）

| 技（routine の `move`） | パス | 女性のターン | 終わりの状態 | 見分けの要点 |
|---|---|---|---|---|
| `basic` | なし | なし | 変化なし | 距離が伸び縮み（On1 は 1 と 5、On2 は 2 と 6） |
| `cbl` クロスボディリード | 男性の**左** | 左 ½ | 反対の端・向かい合う | 男性が左へ 90° 開く（On1 は 2-3、On2 は 7-1）。手は腰〜胸のまま |
| `cbl_inside_turn` | 男性の**左** | 左 1½ | 反対の端 | 横断中に手が女性の頭上に上がる |
| `cbl_outside_turn` | 男性の**左** | 右 1½ | 反対の端 | 回る直前に小さな逆向きのプレップ、手が外へ振り出される |
| `reverse_cbl` | 男性の**右** | 右 ½ が多い | 反対の端 | 男性が**右**へ開く |
| `right_turn` | なし | 右 1（2回なら 2） | 同じ端 | 頭上で手が時計回りの円。左右位置は変わらない |
| `left_turn` | なし | 左 1 | 同じ端 | 頭上で手が反時計回り |
| `leader_turn` | なし | なし（男性が回る） | 同じ端 | 回っているのが男性。On1 は 1-2-3、On2 は 5-6-7 |
| `copa` | 行って**戻る** | 左 ½ + 左 ½ | **同じ端** | 3〜4 で女性が男性の胸の前に背中を見せて止まる。握手が多い |
| `hand_change` | なし | なし | 手だけ変わる | 男性の背中・頭上で持ち替える |
| `wrap` | なし | 左 ½〜1 | 並ぶ・同じ向き | 女性の両腕が**お腹の前**で交差 |
| `hammerlock` | なし/あり | 左が多い | 片腕が**背中**に | 正面から片腕が消える |
| `shadow` | なし | ½ | 男性が真後ろ・同じ向き | 2人が縦に重なり、同じ足が出る |
| `dip` | なし | なし | 女性が後ろへ倒れる | 頭の高さが急に下がる |
| `shine` | なし | 各自 | 手を離して向かい合う | 接触なし・距離 1〜2m |
| `other` | — | — | — | 上に無いもの。`name` に動きをそのまま書く |

キューバン（カジノ）は名前を併記する: Dile que no ≒ `cbl`、Enchufla = 女性が男性の**右脇**を左 ½ で抜けて両者が逆回りに入れ替わる（`reverse_cbl` の円運動版）、Vacílala ≒ 手を離した `right_turn`（移動しながら2回）。

紛らわしい組の決め手:
- **入れ替わったか**（7 の時点で端が変わったか）→ CBL 系 / その場ターン・コパ を分ける。
- **最後に女性がどちらの端か** → コパ（戻る）と CBL アウトサイド（反対へ）を分ける。
- **½ で止まって来た道を戻る**のはターンではない（ハーフターン＋チェック）。
- **体が回らず手だけ頭を越える**のはヘアコーム。ターンと書かない。

## 4. カメラ1台で見えないときの推定規則

### 4.1 推定の手順 — 隠れる前と出てきた後をつなぐ

隠れている間は見ない。代わりに**隠れる直前の状態と出てきた直後の状態**を比べ、
その差を説明できる部品の組み合わせのうち、辞書で最も普通のものを選ぶ。

1. 端が入れ替わったか → パスの有無
2. どちらが手前だったか × 始まる前に男性がどちらを向いていたか → 通る側（4.2）
3. 隠れている間に見えるもの（4.3）→ ターンの有無・向き
4. 時間 → 回数（1回転 ≈ 2拍。隠れていた拍数より多い回数は採らない）

決めた値には「見えた（seen）」か「推定（inferred）」かを必ず付ける。

### 4.2 女性が男性の後ろ（カメラの奥）を通るケース

カメラから見て女性が男性の奥を通るとき、女性の体は男性に隠れる。通る側は次の表で決まる
（上から見た方位: E=画面右・W=画面左・S=カメラ側・N=奥。男性は始まる前、女性の方を向いている）。

| 始まる前の男性の向き | 女性が手前（S）を通る | 女性が奥（N）を通る |
|---|---|---|
| W（画面左を向く） | 男性の**左** | 男性の**右** |
| E（画面右を向く） | 男性の**右** | 男性の**左** |

だから「奥を通るインサイドターン」は珍しい技ではない。男性が画面右を向いていれば普通の
CBL インサイドターン（男性の左を通る）が、カメラからは奥に隠れて見えるだけである。

### 4.3 体が隠れていても見える手がかり

| 手がかり | 意味 |
|---|---|
| 男性のリードの手（多くは左手）が**頭より上**に上がる | ターンがある。手が腰〜胸のままなら回っていない（ただの CBL） |
| 上がった手が最初に**内側（2人の間）**へ動く／**外側**へ振り出される | 内側 = 左回転（インサイド）、外側 = 右回転（アウトサイド） |
| 回り始める直前（On1 は 3、On2 は 1 前後）に手が一瞬逆向きに小さく動く（逆プレップ） | アウトサイド（右回転）の前触れ |
| 男性の肩越しに見える女性の頭・顔の向きの順番 | 3コマ以上続けば回転の向き（0.1秒刻みで 1コマ 50〜60° 進む） |
| 隠れる直前・出た直後の女性の向き | 回り始め・回り終わりの向き。間の量は時間と辞書で補う |
| 隠れていた拍数 | 1拍 ≈ 0.3秒。普通の CBL の横断は約2拍（On1 は 5-6、On2 は 1-2）。1 回転 ≈ 2 拍なので、隠れていた拍数より多い回転は書かない |

向きの手がかりが何も無いときは、ターンがあることだけ書き、向きは空欄にする（`direction: null`）。
CBL 中に手が頭上に上がった回転は左回転（インサイド）が最も多いが、それは推定として書く。

## 5. 書き方（ダンサーが読んで再現できる形）

1×8 ごとに1行。**前の技の出口から始めて**、部品を順に書く:

> 【1-2-3】（On2）男性左手×女性右手のまま、男性が 7-1 で左へ開き、女性が 2 で男性の左を通りながら左に 1½ 回転（インサイドターン）、5 で回り切る。出口で端が入れ替わり、手はそのまま。

- 技名に自信が無いときは、技名を外して部品だけを書く。部品が書けていればダンサーは再現できる。
- 人は「男性」「女性」、手は「男性◯手×女性◯手」で呼ぶ。
