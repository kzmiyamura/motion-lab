# サルサ・パートナーワーク リファレンス（映像解析用）

対象読者: 0.1 秒刻みのフレームストリップを見て、カップルの振付を「動画を見なくても再現できる」文章に起こすモデル。
範囲: LA スタイル On1 / NY スタイル（マンボ）On2 / キューバン・カジノ（ルエダ）。
注意: 技名は流派・地域・教室でかなり揺れる。本書は複数の出典を突き合わせて要約したもので、出典どうしで食い違う点は「⚠ 揺れ」として明記した。迷ったら**技名より「動きそのもの」（持ち手・回転方向・回転数・移動経路・カウント）を書く**のが安全。

---

## 0. 本書の座標と用語の約束

| 用語 | 本書での定義 |
|---|---|
| Leader（L） / Follower（F） | リーダー（多くは男性） / フォロワー（多くは女性） |
| 右回転 right turn / clockwise (CW) | **真上から見て時計回り**。本人の右肩が後ろへ引ける回転 |
| 左回転 left turn / counter-clockwise (CCW) | 真上から見て反時計回り。本人の左肩が後ろへ引ける回転 |
| Inside turn | 標準的なサルサ用語ではフォロワーの**左回転（CCW）**。持ち手がカップルの内側（2人の間）へ向かって動き始める回転 |
| Outside turn | フォロワーの**右回転（CW）**。持ち手がカップルの外側へ向かって動き始める回転 |
| Slot（スロット） | LA/NY の線状の踊り場。2人はこの直線の両端を行き来する |
| CBL | Cross Body Lead。フォロワーがリーダーの前を通ってスロットの反対端へ移る技 |
| 「リーダーの左側を通る」 | リーダーの**元の正面向き**を基準にした左右 |
| 1×8 | 8 カウント（2 小節）1 回分 |

⚠ 揺れ: inside / outside の定義は教室によって異なる。サルサの主流は上記（inside = フォロワー左回転）。バチャータ系では「フォロワーの腕が自分の体の前を横切る＝inside」と腕の軌道で定義することがあり、サルサでもその流儀の先生がいる。**記述では必ず「右回転（時計回り）」「左回転（反時計回り）」も併記する**こと。

### 0.1 単眼カメラでの回転方向の判定（重要）

カメラが正面（観客側）にあり、ミラー反転されていない映像を前提とする。

| 開始時の向き | 右回転（CW） | 左回転（CCW） |
|---|---|---|
| 顔がカメラ向き | 鼻・顔が**画面左**を向く → 背中 → 画面右 → 正面 | 鼻が**画面右**へ → 背中 → 画面左 → 正面 |
| 背中がカメラ向き | 鼻・横顔が**画面右**に出る → 正面 → 画面左 | 横顔が**画面左**に出る → 正面 → 画面右 |

- 自撮り・練習スタジオの鏡越し・インカメラ映像は左右反転していることがある。反転していると右回転と左回転が入れ替わる。ロゴや文字、時計で反転を確認する。
- 0.1 秒刻みの場合: テンポ 160〜210 BPM では 1 拍 ≈ 0.29〜0.375 秒 ≈ **3〜4 フレーム**。1×8 ≈ 2.3〜3.0 秒 ≈ **23〜30 フレーム**。
- 1 回転（360°）は普通 2 拍（6 前後のフレーム）で回る。1 フレームあたり 50〜60° 動くので、**連続 3 フレーム以上**で顔→横顔→背中の順序を確認しないと方向を取り違えやすい。ダブルターン（720°）では 1 フレームあたり 100°を超えることがあり、エイリアシングで逆回転に見える。その場合は足の踏み替え順と腕の輪の回り方で確かめる。

## 1. カウント構造

### 1.1 基本ステップの共通形

- 8 カウントのうち **1-2-3 と 5-6-7** で踏み、**4 と 8** は止まる（または小さなタップや体重保持）。リズムは quick-quick-slow。
- 「ブレイク break」は進行方向が切り替わる 1 歩。On1 / On2 の違いは、**ブレイクがどのカウントに来るか**で決まる。

### 1.2 On1（LA スタイル。キューバンも基本は「1 で踏み始める a tiempo」）

| カウント | リーダー | フォロワー |
|---|---|---|
| 1 | **左足を前へ（前ブレイク）** | 右足を後ろへ（後ろブレイク） |
| 2 | 右足に体重を戻す | 左足に戻す |
| 3 | 左足を揃える | 右足を揃える |
| 5 | 右足を後ろへ（後ろブレイク） | **左足を前へ（前ブレイク）** |
| 6 | 左足に戻す | 右足に戻す |
| 7 | 右足を揃える | 左足を揃える |

- 回転やパスの**実行**は、回る本人の「前ブレイク側の半分」で起こるのが原則。
  - フォロワーの回転・CBL の横断は **5-6-7**（ピボットは 5〜6）。
  - リーダー自身の回転は **1-2-3**。
  - プレップ（予備動作）は直前の半分で行う。フォロワーの回転なら 1-2-3、特に 3 で入る（いわゆる J-prep）。
- 例: 右ターン（On1）では、1-2-3 でリーダーが左手を J 字に下げて引き戻すプレップを入れ、5-6-7 でフォロワーが右回転する。
- 例: CBL（On1）では、1-2-3 でリーダーが前に出て、3 で 90° 左へ開いて通り道を空ける。5-6-7 でフォロワーが前を横切り、5〜6 で半回転する。

### 1.3 On2（NY スタイル / マンボ。Eddie Torres 系）

| カウント | リーダー | フォロワー |
|---|---|---|
| 1 | 左足を小さく後ろへ（準備の 1 歩） | 右足を小さく前へ |
| 2 | **右足を後ろへ（後ろブレイク）** | **左足を前へ（前ブレイク）** |
| 3 | 左足を戻す | 右足を戻す |
| 5 | 右足を小さく前へ | 左足を小さく後ろへ |
| 6 | **左足を前へ（前ブレイク）** | **右足を後ろへ（後ろブレイク）** |
| 7 | 右足を戻す | 左足を戻す |

- フォロワーの前ブレイクは 2 に来る。したがって**フォロワーの回転・横断は主に 1-2-3 側（ピボットは 2〜3）**に来る。On1 とはちょうど半小節ずれる。
- On2 はブレイクの直後に slow が来るので、回転に使える時間が長い。そのためターンやスピンが「ゆったり、流れる」ように見える。
- 別系統の Power On2 / Palladium 系は 2-3-4・6-7-8 で踏み、1 と 5 を空ける。
- ⚠ 揺れ: On2 で CBL を 1×8 のどこから数え始めるかは教室によって違う。カウントを書くときは、「フォロワーが横断して半回転するのは何拍目か」を観測値として書くのが確実。

### 1.4 キューバン（カジノ / ルエダ）

- 基本は「1 で踏み始める」（a tiempo）。contratiempo（2 で踏む）で踊る人もいる。
- 基本ステップのガペア（Guapea）では、**1 で 2 人とも後ろへロック（離れる）し、5 で寄る**。
  - 典型例は、リーダーが 1 に左足を後ろ、フォロワーが 1 に右足を後ろ。
  - LA の On1 では 1 でリーダーが前に出る。2 人とも同時に後ろへ下がるのがガペアの特徴。
- 線状のスロットはない。**カップルが互いの周りを回る円運動（circular）**が主体で、リーダーも大きく位置を変える。
- ルエダ（Rueda）は複数のカップルが円を作り、コーラー（cantante）の号令で同じ技を一斉に踊る。Dame などの号令でパートナーが交代する。

### 1.5 映像から On1 / On2 / キューバンを見分ける手順

1. **フォロワーが回る・横断するのが 8 カウントのどちら側か**を見る。
   - 曲のフレーズ頭（ボーカルや管の入り、伴奏の切り替わり）を 1 とする。
   - 回転が 5-6-7 にあれば On1、1-2-3 にあれば On2 の可能性が高い。
2. **リーダーの左足の前ブレイク**を見る。
   - 1 で左足が前に出ていれば On1。
   - 6 で左足が前、2 で右足が後ろなら On2。
3. **音のアクセント**を手がかりにする。
   - On2 のブレイク（2・6）はコンガのスラップ／オープントーンやベースの動きに合う。
   - On1 は 1 拍目（フレーズ頭、カウベルの 1-3-5-7）に合う。
4. **形**を見る。
   - 一本の線上で場所を入れ替え続けていれば LA/NY。
   - 2 人が円を描いて回り、手をつないだまま互いの周りを歩き続け、1 で 2 人とも下がるならキューバン。
   - キューバンは技名（enchufla, dile que no …）で書く方が、ダンサーには伝わりやすい。
5. 曲の 1 拍目が特定できない場合は「On1 / On2 不明。フォロワーの横断は 8 カウント中の後半（または前半）」のように、**相対表現で書く**。

⚠ 本プロジェクト固有の観測メモ（ユーザー確認済み）: 「カウント 1 は男性が左足、女性が右足」「On1 は 3・4・7・8 でニュートラル」「On2 は一度も足が揃わない」。

### 1.6 スロットの概念

- **LA / NY（linear）**: 2 人は 1 本の直線（slot）の両端にいる。CBL のたびに端を入れ替え、互いの向きは 180° 反転する。
  - リーダーは通り道を空けるために、一度スロットの外へ半身ずれる（90° 開く）。
  - 映像では、2 人の位置が画面上で左右（または奥手前）に交互に入れ替わる。
- **Cuban（circular）**: スロットはない。リーダーがフォロワーの周りを回る、またはカップル全体が回転する。
  - Dile que no を終えた位置で、フォロワーがリーダーの左側にいる。
  - ガペア（開いた向かい合わせ）では、フォロワーがリーダーの右側寄り（pa'l medio の位置）に来る。
  - 「左右どちら側に立っているか」が技の起点を決める。

## 2. 持ち手（Hand-hold）の表記と、カメラでの見え方

| 表記（英） | 意味 | カメラでの見え方・手がかり |
|---|---|---|
| **Closed position / closed hold** | L の右手を F の左肩甲骨に置き、L の左手で F の右手を持つ。F の左手は L の右肩・上腕に置く | 体が近い（約 30cm 以内）。L の右腕が F の背中に回って隠れる。F の左手が L の肩の上に見える |
| **Open position（double hand, open）** | 両手を向かい合わせで持つ（L 左–F 右、L 右–F 左）。腕は交差しない | 2 人の間に平行な 2 本の腕。腰〜みぞおちの高さ。間隔は腕 1 本分 |
| **Left-to-right（L→R, normal single）** | L の左手が F の右手を持つ。最も標準の片手 | つないだ手が 2 人の間の片側（L から見て左、F から見て右）にある。腕は体の正中線を横切らない |
| **Right-to-left** | L の右手が F の左手を持つ | 上の左右反対版 |
| **Right-to-right（handshake / crossed single）** | 握手の形。右同士 | **つないだ腕が 2 人の間を斜めに横切る**。両者とも右腕が自分の体の前を横切る |
| **Left-to-left** | 左同士 | 斜めに横切る（逆向き） |
| **Cross hand / crossed double hold（R over L）** | 右同士・左同士で両手を持ち、右手が上 | 2 人の間で**腕が X 字に交差**し、右腕が上に重なる。右回転（outside turn）系の前触れ（Copa、Sombrero、Titanic、Butterfly） |
| **Cross hand（L over R）** | 左手が上で交差 | X 字の上側が左腕。左回転側の技の前触れ（Setenta の入り、一部の Butterfly） |
| **Hammerlock（HL）** | 片腕が自分の背中に折り曲げられた状態で持たれている | 背中側の腰の高さに、曲がった前腕が見える。F の右腕が背中に回るのが最多。**L の HL** もある。正面から見ると片腕が「消える」 |
| **Half hammerlock / broken arm** | 背中に回った腕の手だけを持つ | 片腕だけ背中、もう片手はフリー |
| **Cuddle / Cradle / Wrap / Sweetheart / Basket** | 両手を持ったまま F が L の横（主に右）に入り、F の両腕が自分の腹の前で交差する。L の右腕が F の腰を抱く | 2 人が**同じ方向を向いて並ぶ**。F の腕が胸〜腹の前で交差し、L の腕が F の体を巻く |
| **Shadow position** | L が F の真後ろに立ち、同じ向き。手は F の手や腰、または離す | カメラから見て 2 人が縦に重なる（奥の人の頭が手前の人の肩の後ろから見える）。同じ足のフットワーク |
| **Titanic** | Shadow の一種。L が F の真後ろで、両腕を横に広げて持つ（F の腕が W 字や翼の形） | 後ろの L の腕に支えられて、F の両腕が水平〜W 字に広がる |
| **Sombrero（帽子）** | 交差した両手が 2 人の首・肩の後ろに掛かる。L の左腕が自分の頭の後ろ、右腕が F の頭の後ろ | 2 人が並んで同じ向き。両腕が頭の後ろを通り、肘が上がった「帽子」の形 |
| **Butterfly** | 交差した両手を大きく左右へ開く | 腕が大きく横に開いた X 字 |
| **Waiter hold** | 手のひらを上向きにし、頭の上でトレイを持つように支える | 頭上に掌を上にした手。直後に回転が来る |
| **Halo / fingertip hold** | 回転中、頭上で指先を軽く引っ掛ける | F の頭の真上で、L の手が小さな円を描く |
| **Neck wrap / neck loop** | 回転させたあと、腕を F（または L）の首の後ろに掛ける | 首の後ろに前腕が水平に掛かる |
| **Gancho（キューバン）** | L の肘が F の上腕の上から掛かる | L の肘が F の腕の上に乗っている |
| **Pa'l medio（キューバン）** | L が F の左側。L の右手は F の背中、F の左手は L の右肩。L 右–F 右を肘を曲げて L 字に持つ | 横並びに近い向かい合わせ。曲げた腕が L 字 |
| **Guapea position（キューバン）** | 両手を平行に持つ向かい合わせ（L 左–F 右、L 右–F 左） | Open position と同じ形 |

### 2.1 手の替え方（hand change）の表現

- 「behind the back」: L が自分の背中の後ろで、F の手を右手から左手（またはその逆）へ持ち替える。
  - 映像では、L の両手が一瞬背中側に隠れる。その間 L はやや横向き〜背中を見せる。
- 「over the head」: 持ち替えが頭上で起こる。
- 「hair comb / comb」: F の手を F 自身の頭の上から後ろへ撫でるように通して下ろし、離す。回転はしない。
- 「hand toss / throw」: 手を投げ上げて離し、相手が回る。
- 「drop / pick up」: 手を離す・つなぎ直す。
- **書き方の例**: 「6 で L が右手で F の右手を受け取り、左手を離す（L→R から R→R へ）」のように、**何拍目に・誰のどの手が・どの手に**移ったかを書く。

## 3. 技の辞書（Pattern dictionary）

各項目の書式は以下のとおり。

- **別名 / キューバン名**
- **開始 → 終了の持ち手**
- **回る人・方向・回転数**
- **カウント**: On1 基準。On2 はフォロワーの動きを 4 拍前（1-2-3 側）へずらして読む
- **F の経路**
- **開始 → 終了の位置**
- **映像での手がかり**

回転数の表記は 1 = 360°、½ = 180°。

### A. 基本・位置系

#### A1. Basic（Forward/Back basic, Mambo basic）
- 持ち手: Closed または Open。回転なし。
- カウント: 1-2-3 / 5-6-7。L は 1 で前（On1）。
- 経路: その場で前後に揺れる。位置は入れ替わらない。
- 手がかり: 2 人の距離が 1 と 5 で周期的に伸び縮みする。

#### A2. Side basic / Side step
- 前後の代わりに左右へ踏む。Closed のまま横へ揺れる。
- 手がかり: 2 人の距離が変わらず、頭が左右に揺れる。

#### A3. Cuban basic / Guapea（キューバン）
- 持ち手: Guapea（両手を平行）または片手（L 左–F 右）。
- カウント: 1 で両者とも後ろへロック（離れる）、5 で寄る。L は左手を下から外へ振る動きがある。
- 手がかり: 2 人が**同時に**離れ、同時に寄る。LA の基本では一方が前・一方が後ろ。

#### A4. Open break
- Closed から 1（または 5）で後ろへブレイクして片手（通常 L→R）に開く。次の技の入口。
- 手がかり: 体が離れ、L の右手が F の背中から外れる。腕が伸びて張る（テンション）。

#### A5. Pa'l medio / Caminamos（キューバン）
- Pa'l medio の持ち方のまま、カップルで円周上を歩く。pa'rriba = 反時計回り、pa'bajo = 時計回り。

#### A6. Shines（シャイン）
- 手を離し、向かい合って各自がフットワークを踊る（Suzie Q、cross-over、spot turn など）。
- 手がかり: 接触がない。2 人の距離は 1〜2m。左右対称または同じ動き。

### B. Cross Body Lead 系

#### B1. Cross Body Lead（CBL） ≒ キューバン **Dile que no（DQN）**
- 開始: Closed または L→R。終了: 同じ持ち手（片手なら L→R）。
- 回転: F は 5-6 で**左へ ½（CCW 180°）**。L は 3 で左へ ¼、7 でさらに左へ ¼（合計 CCW 180°）。
- カウント（On1）:
  - 1-2-3: L が前ブレイクして、3 で 90° 左へ開き、スロットを空ける。F は後ろブレイクして戻る。
  - 5-6-7: F が L の前を一直線に横切り、5〜6 で半回転し、7 で向き直る。
- F の経路: **L の左側**（L の元の正面向きに対して）を通り、スロットの反対端へ。
  - L の体のすぐ前を通る。L の右手が F の背中（肩甲骨）に添えられて送り出す。
  - West Coast Swing の "left side pass" に相当する。
- 位置: 2 人が端を入れ替え、両者の向きが 180° 反転する。
- 映像の手がかり:
  - 3 で L が横向き（体を 90° 開く）になる。
  - 5〜6 で F が L の正面を横切りながら、L の胸の前で背中または横顔を見せて回り込む。
  - 7 で 2 人の左右が入れ替わっている。L の左手は腰〜胸の高さのまま（頭上に上がらない）。
- DQN（キューバン）: Pa'l medio / ガペアから行い、F は CCW で L の前を横切り、L の左側に出る。開いた位置（ガペア）に戻る。LA の CBL より円弧を描く。
  - ⚠ 揺れ: 「DQN はルエダでは号令で、パートナーを替えずに元の相手と踊り続ける合図」という説明もある。動きとしては CBL と同じとする出典が多い。

#### B2. CBL with inside turn（インサイドターン付き CBL）
- CBL の横断中（5-6-7）に、F が**左回転を追加**する。合計 **1½ 回転 CCW（540°）**。
- L の左手（F の右手を持つ）が 5 で頭上へ上がり、F の頭上で**反時計回りの小さな円（halo）**を描く。L は時計回りに F を回り込んで、F の移動距離を短くすることがある。
- 手がかり:
  - CBL と同じく位置が入れ替わる。
  - 横断中に F の腕が真上に上がり、F が 1 回以上回る。
  - 回転方向は F の左肩が引ける方向。
- 派生:
  - 回転のきっかけ（リード点）で分かれる: Shoulder turn（L の右手で F の肩から回す）、Hip turn（腰から）、Free spin（手を離して回す）。
  - 回転数で分かれる: Double inside turn（2½）など。

#### B3. CBL with outside turn（アウトサイドターン付き CBL）
- 横断中に F が**右回転（CW）で 1½（540°）**。
- L の左手は 3 で小さな逆向きのプレップを入れる。5 で外側（L から見て左）へ振り出し、F の頭上で**時計回り**の円を描く。
- 手がかり: 位置は入れ替わる。F の回転方向は右肩が引ける方向。回り始めに腕が 2 人の外側へ開く。

#### B4. Reverse CBL / Inside CBL / Right side pass
- 通常の CBL とは逆に、F が **L の右側**を通って反対端へ移る。L は右へ開いてスロットを空ける。
- 持ち手は R→R または L→R。F は横断中に右へ ½ 回転（CW）することが多い。
- 手がかり:
  - L の体が通常 CBL と逆向きに開く（3 で右へ 90°）。
  - F が L の背中側の空間の近くを通る。
  - ⚠ 揺れ: "inside CBL" を「インサイドターン付き CBL」の意味で使う先生もいる。

#### B5. 360° CBL（Full / continuous CBL）
- CBL の回転を続け、2 人が **CCW に一周して元の位置・元の向き**に戻る。2×8 に及ぶこともある。
- 手がかり: 横断が起きたように見えるが、最後は元の端に戻る。カップル全体が反時計回りに回る。

#### B6. Double CBL / CBL with leader's turn（Suave など）
- CBL の途中で L 自身も左回転する。または CBL を 2 回連続する。
- 手がかり: L も 1 回転する（5〜7 付近）。

#### B7. Open CBL / Catwalk（片手 CBL）
- L→R の片手だけで CBL を行い、7 で F を右回転させて終える（Catwalk）。
- 手がかり: L の右手が F の背中に添えられない。腕 1 本で引き込む。

#### B8. CBL with hand change（持ち替え付き CBL）
- 横断中または 7 で、L の左手から右手（R→R、握手）に持ち替える。次の技（Copa など）への準備。
- 手がかり: 7 で、つないだ腕が 2 人の間を斜めに横切る形（握手）に変わる。

#### B9. Tunnel / Lady's tunnel（トンネル）
- CBL の横断中に、L の左腕（F の右手）でアーチを作り、F がその下をくぐる。回転はしない。
- 手がかり: F の頭のすぐ上に腕のアーチがある。F は回らず、まっすぐ歩いて抜ける。

### C. ターン系

#### C1. Right turn（F の右ターン） ≒ Outside underarm turn。キューバンでは Vuelta、手を離せば Vacilala
- 持ち手: L→R（指先で軽く）。両手、または交差で行うこともある。
- カウント（On1）: 1-2-3 でプレップ（L の左手が下がって J 字を描く、または 3 で軽く押す）。5-6-7 で F がその場で右へ 1 回転（CW 360°）する。
- 経路: その場（spot turn）。位置は入れ替わらない。L は 5-6-7 で一歩下がり、空間を作る。
- 手がかり: F の頭上で L の手が**時計回りの円**を描く。回転後も 2 人の左右位置は変わらない。

#### C2. Left turn（F の左ターン）
- 同じくその場で、F が左へ 1 回転（CCW）。L の手は頭上で反時計回りの円を描く。
- 手がかり: C1 と方向が逆。プレップでは手が内側へ引かれる。

#### C3. Inside turn / Outside turn（位置入れ替え型）
- オープンブレイクのあと、F が前進して L と場所を入れ替えながら回る。
- 定義: Inside = 左回転、Outside = 右回転。多くの教室では「CBL + 1½ 回転」を指すので B2 / B3 と同じ。
- 手がかり: 回転＋位置の入れ替えがある。入れ替わりがなければ C1 / C2（その場の回転）。

#### C4. Leader's underarm turn（L 自身の右 / 左ターン）
- L が自分の左手（F の右手を持ったまま。waiter hold で頭上へ上げる）の下で回る。On1 では L の前半 1-2-3 で行う。
- 手がかり: 頭上の腕の下で回っているのが L。F はその場でベーシック。

#### C5. Spot turn（その場ターン、L / F）
- 手を離し、各自がその場で 1 回転する。L は 1-2-3、F は 5-6-7 が多い。
- Back spot turn = Hook turn（C7）の別名として使われることがある。
- 手がかり: 接触がないまま 1 回転し、また手をつなぐ。

#### C6. Double / multiple turns（ダブルターン）
- 右（または左）に 2 回転以上。L の手は頭上で連続して円を描く。
- On2 では slow が回転側に来るため、多回転が入れやすい。

#### C7. Hook turn（フックターン） ≒ Back spot turn
- 片足をもう一方の足の後ろへフック（交差）させ、その場で回る。多くは右回転（CW）。
  - 例: 5 で右足を左足の後ろへ、6 で 180〜360° 回り、7 で踏み出す。
- L の見せ技としてよく使われ、カジノでも頻出する。
- 手がかり: 回る直前に脚が後ろで交差する。上体が小さく速く回る。

#### C8. Free spin（フリースピン）
- 手を離し、勢いをつけて回らせる（投げる）。F の場合は inside / outside の両方がある。L のフリースピンもある。
- 手がかり: 回転中に接触がない。L の腕が回転直前に振られる（押す・投げる）。

#### C9. Half turn（ハーフターン）と Check（チェック）
- ½ 回転（180°）で止め、来た方へ戻す（check = 止めて送り返す）。
  - Half-and-half: 右へ ½、戻して左へ ½。
  - 1½ のバリエーション: 「Half right → 1½ left」など。
- 手がかり: 180° で止まり、逆方向に戻る。顔の向きが正面 → 横 → 背 → 横 → 正面と往復する。

#### C10. Pencil turn / Check turn
- ほぼその場から動かず、細く高速に回るターン。NY の must-know パターン。
- 手がかり: 足元がほとんど動かない。

#### C11. Spiral turn / Arm spiral
- 回転しながら、F の腕が体に巻き付くように下がっていく。または腕を螺旋状に下ろす装飾。
- ⚠ 名称の定義が出典ごとに曖昧。動きを書くこと。

### D. Copa・チェック系

#### D1. Copa（コパ） / In-and-Out
- 持ち手: 多くは R→R（握手）。両手の交差で行うこともある。L→R で行う教室もある。
- 動き:
  - 「In」（1-2-3）: L が F を引き込み、F は**左へ ½（CCW）**回って L の横〜前に入る。L は右へ ¼ 開く。
  - 「Out」（5-6-7）: F は再び**左へ ½**回りながら、**元来た方へ押し戻される**。L は向きを戻す。
- 結果: F は**元の端に戻る**（位置は入れ替わらない）。F の総回転は CCW 約 360°。
- L の手の軌跡は、低く引いて上げて送り返す「杯（cup）」の形。
- 派生: Copa with a turn and a half、Copa with outside turn（Out で右回転させる）。
  - 1-2-3 の In は固定で、5 / 6 / 7 のどこでリードするかで outside turn・inside turn・walkthrough に変化させる、と教える教室もある。
- 手がかり: F が L の正面すれすれまで来て、背中を L の胸に見せる瞬間（3〜4 付近）がある。その後、元の位置へ戻る。CBL と違い、**7 で 2 人の左右位置が元のまま**。
- ⚠ 揺れ: 「Copa = 両者が同じ方向を向き、互いに逆へ傾いた "goblet" の形から始まる技」と説明する出典もある（jantar.org）。名前より、「F が戻るか、横断するか」を書く。

#### D2. Peek-a-boo / Checked inside turn
- F を左へ ½ 回して止め（L の空いた手で肩や腕を受け止める）、右へ戻す。止めた位置で、L と F が肩越しに顔を合わせる。

#### D3. Shoulder check / Shoulder turn
- L の右手で F の左肩甲骨を押して止める、または肩から回す。
- 手がかり: L の手が F の肩に当たり、F の回転が止まる・逆転する。

### E. ラップ・ハンマーロック系

#### E1. Hammerlock（ハンマーロック、前 / 後ろ）
- 一般形: 両手（または片手）で持ったまま F を回し、F の**右腕を F の背中に折り曲げた**状態で止める。
  - 入り方の例: L→R の手を低く保ったまま F を左回転（inside）させる。腕が背中側に巻き込まれる。
  - 終わり方: 逆回転（右回転）でほどく。または HL のまま L が回り込んで位置を替える。
- 変種（salsaisgood による分類）:
  - 誰の腕か: F の左 HL / 右 HL、L の左 HL / 右 HL。
  - 持ち手: 通常持ちか、交差持ち（reverse HL）か。
- 「前の HL」は向かい合ったまま。「後ろの HL」は F が L の横〜前で同じ向きになる。
- 手がかり: F の片腕が腰の後ろで横向きに折れ、正面からは見えない。L の手もその背中側にある。

#### E2. Cradle / Cuddle / Wrap / Sweetheart / Basket（ラップ）
- 開始: Open（両手）。L の左手を F の頭上へ上げ、F を左（inside）へ ½〜1 回転させる。
- 終了: F が L の右側（または左側）に並び、**F の腕が自分の前で交差**する。L の右腕が F の腰に回る。同じ方向を向く。
- 出口: Unwrap（右回転で外へほどく）、Sidestep（L が F の反対側へ移る）、Wrap の位置で回る、など。
- 手がかり: 2 人が並び、同じ向きでベーシック。F の両手首が F の腹の前で交差して見える。
- 「Barrel roll」は Wrap の状態で L がフックターンし、背中合わせになる変種。

#### E3. Neck wrap / Neck loop / Neck roll
- F（または L）を回したあと、持ち手を相手の**首の後ろに掛けて**止める。そこから首に沿って手を滑らせて回転させるのが neck roll / slide。
- 手がかり: 前腕が首の後ろに水平に掛かる。肘が肩の高さ。

#### E4. Hand change behind the back（背中での持ち替え）
- L が F の右手を左手から右手へ、**自分の背中の後ろ**で持ち替える。持ち替えながら L が右回転することが多い（キューバンの Evelyn など）。
- 手がかり: L が一瞬 F に背を向ける。両手が L の腰の後ろで合わさる。

#### E5. Hair comb（ヘアコーム、F / L）
- 持った手を相手（または自分）の頭の上から後頭部へ通し、撫でるように下ろす。**回転はしない**。
- 手がかり: 手が頭を越えて後ろへ降りるが、体は回らない。初心者の F が誤って回ってしまうことがある。

### F. 交差持ち（Cross hand）・並び系

#### F1. Cross-hand right turn / Butterfly
- R over L の交差両手から、F が右回転する。腕の交差がほどける（または二重に交差する）。
- Butterfly は腕を大きく左右へ開いた形を見せる（L over R の交差）。
- 手がかり: 開始時の X 字、回転後の腕の形。

#### F2. Sombrero（LA / キューバン共通の名前）
- 開始: Cross hand（R over L）。
- 動き:
  - F は**右回転（CW）を 1〜2 回**しながら、L の前を通って L の**右側**へ移る。
  - L はやや左へ寄り、F の移動を短くする。
  - 回転後、L は自分の左腕を自分の頭の後ろへ、右腕を F の頭の後ろへ掛ける（帽子）。
- 終了: 並んで同じ向き（F が L の右）。キューバンでは手を離して DQN で抜ける。LA では CBL などで抜ける。
- カウント: キューバンでは 1×8 で 2 回転し、次の 1×8 で帽子 → DQN。
- 手がかり: 2 人とも肘が頭の高さに上がる。両腕が 2 人の首の後ろを通る（F の頭の後ろに L の右前腕）。
- ⚠ 揺れ: 「L が F の左側」と書く資料もある（Salsa Gente の Sombrero arms）。終了時の左右は映像で確認して書く。

#### F3. Titanic（タイタニック）
- L が F の**真後ろ**に入り、2 人とも同じ方向を向く。両腕を横に広げる（F の腕が W 字や翼の形）。
- 入り方の例: R→R・L→L の交差持ち（左が上）で CBL を始め、F の横断中に L が F の後ろへ回り込む。
- 抜け方: F を前へ送り出し、右回転させる。
- NY の "Half Moon with turn and a half" を Titanic と呼ぶ教室もある。
- 手がかり: 2 人が縦に重なり、手前の F の両腕が水平に開く（映画のポーズ）。
- ⚠ 揺れ: 定義の幅が大きい。

#### F4. Shadow position の技（Shadow turns / Shadow walk）
- L が F の後ろに付き、同じ足で踊る。入り方は、L が half spot turn で F から背を向ける、または F を ½ 回して L の前に置く。
- そこから F を右回転させたり、フリースピンさせたり、手を持ち替えて前へ出す。
- 手がかり: 縦に重なる。同じ足が同時に出る（鏡像ではない）。

#### F5. Walk-around / Follower circles leader
- F が L の周りを一周歩く（多くは L の背中側を回る）。L は持ち手を自分の頭や首の後ろに通して受け渡す。
- 手がかり: F が L の後ろに一時的に隠れる（オクルージョン）。L はほぼその場。

#### F6. Around the world（アラウンド・ザ・ワールド）
- 一般的な理解: F が L の周りを 360° 回る、または L が持ち手を自分の頭の周りに一周させる。
- ⚠ 確証の取れる出典を見つけられなかった。教室ごとの名前と考え、動きで記述すること。

#### F7. Back-to-back（背中合わせ）
- Wrap や Hammerlock から L がフックターンし、2 人が背中合わせになる（Barrel roll）。
- 手がかり: 2 人の顔が反対を向き、背中同士が接する。

### G. キューバン（カジノ / ルエダ）の主要技

技名は号令（コール）。カウントは 1-2-3 / 5-6-7。

#### G1. Guapea
- 基本の待機ステップ（A3）。技と技の間に必ず挟まり、ルエダではタイミング合わせに使う。

#### G2. Dile que no（DQN）
- B1 を参照。Pa'l medio / ガペアから、L が 1 で左足を前（やや F 寄り）へ出す。
- L は右手を F の腰の後ろに当て、F を左回転で L の前を横切らせる。F は L の左側へ出て、開いた位置に戻る。
- 多くのキューバン技はこの DQN で終わる。

#### G3. Enchufla（エンチュフラ / Enchufe）
- 開始: ガペア（Open）。
- 動き:
  - 1-2-3: L が後ろへブレイクし、F を前へ歩かせる。
  - 3-(4)-5: F が L の**右側**を通りながら、L の左手（F の右手を持つ）の下で**左へ ½ ピボット（CCW）**する。
  - 5-6-7: F は再び前へ歩く。L は右回りに回り込み、2 人が互いの周りを逆向きに回って**場所を入れ替える**。
- 結果: 位置が入れ替わる。ルエダでは、7 で L が次の F へ移る。
- 続き方:
  - Dile que no
  - Caída（F が L の右側に来る位置。20 以上の技の起点）
  - Rodeo
  - Closed（Adiós への入口）
- 手がかり:
  - L の左腕が F の頭上でアーチを作る。
  - F が CCW に半回転しながら L の右脇を抜ける。
  - L もほぼ同時に CW に回る。2 人が「同じ点を中心に逆回りで 180° 回る」ように見える（Wikipedia の定義）。

#### G4. Exhíbela（エキシベラ） ≒ Sácala
- F の右回転（outside）。F は楕円の軌道を歩く。
  - 1-2-3: 前へ。
  - 3-5: 右へ回って方向転換。
  - 5-6-7: 戻ってくる。
- ルエダでは、F が L の右にいるときにコールされる。L は左手で F を円の内側へ送り、肩を軽く押して回す。
- 手がかり:
  - F が L から離れて右回転し、戻ってくる。
  - 位置は最終的に元に戻る。
  - 回転の頂点で F が L の前を少し離れる。
- ⚠ Exhíbela と Sácala が同じかどうかは出典で異なる（salsaselfie は同一とする）。Exhíbela Inverso は「1-2-3-inside turn-5-6-7-outside turn」。

#### G5. Vacílala（バシララ）
- 7 で L の左手でプレップし、F を**右回転**させる。1-2-3-5-6-7 で移動しながら回る（多くは 2 回転）。そのあと DQN。
- 古典的には手を離すフリーの右回転。今は手を持ったまま行うものもある。R→R で行う版は "Dedo"。
- 手がかり: F が手を離して（または指先だけで）大きく回りながら移動する。L は F を「眺める」スタイリングを入れることが多い。

#### G6. Setenta（セテンタ、"70"）
- 2×8 以上の複合技。
  - ① 7 で交差持ち（L の左手が上、と書く出典がある）にしてプレップ。
  - ② F を回してハンマーロック（F の右腕を背中へ）。
  - ③ バックブレイクしながら、腕を背中の後ろで引いてほどき、場所を入れ替える。
  - ④ L が F の左腕の下をくぐり、もう一度入れ替える。
  - ⑤ Enchufla（complicado）→ DQN。F は L の右側で終わる。
- 手がかり: ハンマーロック → くぐり → くぐり → enchufla → DQN の連鎖。腕が絡んでほどける様子が連続する。
- ⚠ 揺れ: ②の回転方向は出典で食い違う。Dance Central は「F の右回転でハンマーロックへ」、ruedawiki は「F を左へ回す」。映像では回転方向を観測して書く。

#### G7. El Uno / El Dos
- R→R に持ち替え、L→L も取る。L が F の背中側を通って左右に何度も位置を替える（F は前、L は後ろ）。
- 最後に L が F の前を横切りながら、自分で 360° inside turn をし、DQN で終わる。
- El Dos では L が前になる（Danceintime）。
- 手がかり: L が F の後ろを左右に往復する。両手はつないだまま、F の前で腕が交差したりほどけたりする。

#### G8. Adiós
- ガペア（L→R）から、L が F と一緒に右へ回る（またはバックスポットターン）。L は最後に腕の下をくぐり、ルエダでは次の相手へ（Dame）。
- ⚠ 揺れ: 「L が自分の左腕の下をくぐる」（Salsa Gente）と「F の左腕の下をくぐる」（Dance Central）で出典が分かれる。
- Adiós con la hermana = Adiós → Enchufla → 同じ相手と DQN（3×8）。

#### G9. Coca-Cola
- DQN の途中で、F が**左へ移動しながらピボット回転**を追加する。
  - 5-6-7 で 3 歩、1 歩ごとに約 180°（瓶の蓋を開けるような回転）。
  - L は 3 で左手を上げて合図する。
- 片手・両手・交差の版がある。
- 手がかり: 横断中に、F が小刻みに CCW のピボットを重ねる。

#### G10. Kentucky
- F の inside turn で Cuddle に入れ、L が回って向きを変える。L の右手は F の肩、左腕は頭上を通る。最後は DQN。
- 手がかり: Cuddle の形と、L の腕が頭上を越える動き。

#### G11. Siete（7）
- 7〜8 でプレップ（Vacílala と同様）。
  - 1-2-3: F が L の左腕の中に巻き込まれる（カール）。
  - 5-6-7: ほどけて元へ戻る。
- Siete con Coca-Cola は、ほどくときに腕を上げて回す。

#### G12. Paséala（パセアラ）、Sombrero、Montaña、Abanico など
- Paséala は F を L の周りで歩かせる系の技。
- Sombrero は F2 を参照（キューバンの Sombrero は 2 回転の右ターンで並び、帽子を作り、DQN で抜ける）。
- その他は教室ごとの差が大きい。⚠ 映像で動きを観測して書く。

#### G13. ルエダの移動コール
- Dame: 次の相手へ（DQN の足で移動）。
- Dame dos: 2 人先へ。
- Arriba / Abajo: 円の進行方向。
- Al centro / Pa'l medio: 中心へ。
- 振付の記述では「パートナーが替わったかどうか」を必ず書く。

### H. その他

#### H1. Dips（ディップ）
- F を後ろへ倒す。代表的なのは Copa の入りで F を回し、5〜6 で L の左側へ傾けて倒し、7 で起こす形。
- 手がかり: F の頭の高さが急に下がる（股関節〜肩の高さ）。L は膝を曲げて支える。

#### H2. Leader's free spin / Leader shines
- L が手を離して 1〜2 回転する（右回転が多い）。On1 では 1-2-3 で回ることが多い。

#### H3. Half chase / Chase（追いかけ）
- NY でよく使う。手を離して、L と F が交互に回転・ポーズでスロットを往復する。
- 手がかり: 接触がなく、2 人が交互に回る。

## 4. 講師は組み合わせ（コンビネーション）をどう言葉にするか

### 4.1 講師が毎回必ず入れる要素

1. **区切り**: 「1-2-3」「5-6-7」の半小節ごと、または 1×8 ごとに 1 文。
2. **持ち手**: 開始時と変化した瞬間。「L→R のまま」「6 で握手に持ち替え」など。
3. **誰が**: L / F / 両者。
4. **何を**: break、open、cross、turn、check、comb、wrap、duck（くぐる）、hand change。
5. **方向**: 右 / 左回転と回転数、「L の左側を通って」「元の側へ戻る」など。
6. **終わりの位置と向き**: 位置が入れ替わったか、並んでいるか、誰が前か、互いの向き。
7. **腕の高さと通り道**: 「F の頭上で」「腰の高さのまま」「L の頭の後ろを通して」。
8. **プレップ**: 「3 で L の左手を J 字に下げる」「7 で手を交差させておく」。

### 4.2 よく使われる文の型

- 「**[カウント]** で **[誰]** が **[動作]**。**[どちらの手で / どこを]**、**[方向]** に **[回転数]**。終わりは **[位置・向き・持ち手]**」
- 「1-2-3 で L がオープンし、5-6-7 で F を通す」（入口と実行を半小節で分ける）
- 「CBL と同じだが、5 で左手を上げて 1½ 左回転を加える」（既知の技との**差分**で説明する）
- 「ここまでで F は L の右側、2 人とも同じ方向を向いている」（**中間状態の確認**）

### 4.3 コンビネーションの書き起こし例（筆者の言い換え）

**例 1: CBL → 握手に持ち替え → Copa → Outside turn（LA On1、4×8）**
1. 1×8: Closed から CBL。3 で L が左へ 90° 開き、5-6-7 で F が L の左側を横切って ½ 左回転。7 で L は右手を F の背中から離し、F の右手を右手で受け取る（握手 R→R）。
2. 2×8: 1-2-3 で L が握手の手を低く引いて F を呼び込む。F は左へ ½ 回り、3 で L の右前に背中を向けて入る（Copa の In）。5-6-7 で F を元の端へ送り返す。F はさらに左へ ½ 回って L に向き直る（Out）。
3. 3×8: 1-2-3 で L が握手の手を J 字に下げてプレップ。5-6-7 で F は右へ 1 回転。L の右手が F の頭上で時計回りの円を描く。
4. 4×8: 1-2-3 のベーシックで手を L→R に戻す。

**例 2: Right turn → Hand change behind back → CBL with inside turn（LA On1、3×8）**
1. 1×8: L→R。1-2-3 でプレップ。5-6-7 で F がその場で右 1 回転。
2. 2×8: 1-2-3 で L が F の右手を左手から自分の背中の後ろへ回し、右手で受け取る。その間に L は右へ 1 回転し、F に一瞬背を向ける。5-6-7 は R→R でベーシック。
3. 3×8: 1-2-3 で CBL のオープン（L は 3 で左へ 90°）。5-6-7 で F が横断しながら、L の右手の下で左へ 1½ 回転し、反対端で向き直る。

**例 3: Wrap → Unwrap（LA On1、2×8）**
1. 1×8: 両手 Open。1-2-3 でベーシック。5-6-7 で L の左手（F の右手）を F の頭上に上げて左回転させる。F は左へ 1 回転して L の右側に入り、両腕が自分の前で交差した Wrap になる。同じ方向を向く。
2. 2×8: 1-2-3 は並んでベーシック。5-6-7 で L が左手を上げ、右手を離す。F は右へ 1 回転して元の正面位置へ戻る（Unwrap）。

**例 4: Guapea → Enchufla → Dile que no（キューバン、3×8）**
1. 1×8: ガペア。両者 1 で後ろへロックし、5 で寄る。
2. 2×8: Enchufla。1-2-3 で L が下がり、F を前へ。3-5 で F が L の右脇を抜けながら、L の左手の下で左へ ½ ピボット。5-6-7 で L が右回りに回り込み、場所が入れ替わる。
3. 3×8: Dile que no。L の右手を F の腰に当てて、F を L の前を左回転で横切らせる。F は L の左側へ出て、ガペアの位置に戻る。

**例 5: Sombrero（キューバン、2×8）**
1. 1×8: 7 で両手を交差（右が上）。1-2-3-5-6-7 で F が右回転を 2 回しながら、L の前を通って L の右側へ移動。L は少し左へ寄る。
2. 2×8: 1-2-3 で L が左腕を自分の頭の後ろへ、右腕を F の頭の後ろへ下ろして並ぶ（帽子）。5-6-7 で手を離して DQN に入る。

### 4.4 記述用テンプレート（推奨）

```
[時刻 mm:ss.s – mm:ss.s] 1×8 #n  タイミング: On1/On2/不明
開始: 持ち手=…、位置=F が L の正面/右/左/後ろ、向き=…
1-2-3: L …／F …（手: …、高さ: …）
5-6-7: L …／F …（回転: 右/左 × n、経路: L の右/左側を通過、元の端へ戻る/反対端へ）
終了: 持ち手=…、位置=…、向き=…
技名候補: …（確信度 高/中/低。根拠: …）
```

技名に確信がないときは、**技名を外して動きだけを書く**。それでもダンサーは再現できる。

## 5. 誤認しやすい技のペアと見分け方

| 混同しやすいペア | 見分けるポイント（映像） |
|---|---|
| **CBL with inside turn ↔ CBL with outside turn** | 回転方向で区別する（0.1 節の表で顔の向きの順序を確認）。inside = F の左肩が引ける CCW、outside = 右肩が引ける CW。回り始めの腕: inside は内側（2 人の間）へ引かれてから上がる。outside は外側へ振り出してから上がる。どちらも位置は入れ替わる |
| **CBL ↔ その場の右 / 左ターン（change of place の有無）** | 7 の時点で 2 人の左右（画面上の位置）が入れ替わっていれば CBL 系。同じなら spot turn。CBL では 3 で L が 90° 開く。spot turn では L が開かず、正面のまま少し下がる |
| **CBL ↔ Reverse CBL** | L が 3 で開く向き（CBL = 左へ開いてスロットの右に出る、Reverse = 右へ開く）。F が L のどちら側を通るか（CBL = L の左側、Reverse = 右側） |
| **Copa ↔ CBL with outside turn** | 最後に F がどちらの端にいるかで区別する。Copa = 元の端へ戻る、CBL = 反対端。Copa では F が L の胸の前に背中を向けて一瞬止まる（3〜4）。持ち手は握手（R→R）が多い |
| **Right turn ↔ Half turn + check** | Right turn は 360° 連続で、顔が正面に戻る。Half turn + check は 180°（背中を見せた所）で止まって逆向きに戻るので、顔の向きの順序が往復になる（正面→横→背→同じ横→正面） |
| **Inside turn ↔ Hair comb** | 体が回ったかどうか。Comb は腕が頭を越えるだけで、胴体の向きは変わらない |
| **Wrap（Cuddle） ↔ Hammerlock** | Wrap は F の両腕が**体の前で**交差し、並んで同じ向き。Hammerlock は片腕が**背中に**折れ、多くは向かい合ったまま |
| **Sombrero ↔ Wrap ↔ Titanic** | Sombrero は腕が**首・頭の後ろ**、肘が高く、並ぶ。Wrap は腕が**腹の前**で並ぶ。Titanic は L が**真後ろ**で、腕が**横に開く** |
| **Titanic ↔ Shadow position** | 共に L が後ろ。Titanic は腕を水平に広げたポーズの瞬間。Shadow は腕が自由で、同じフットワークで踊り続ける |
| **Enchufla ↔ CBL with inside turn** | Enchufla は F が L の**右脇**を抜け、L も同時に CW に回り込む円運動。CBL は L の**左側**の直線スロットを通り、L はほぼその場で 90°+90° 向きを変える |
| **Dile que no ↔ CBL** | 動作はほぼ同じ。スタイル（円運動、ガペアから入る、1 で 2 人とも下がる）でキューバンと判断したら DQN と書く |
| **Exhíbela ↔ Right turn（Vuelta）** | Exhíbela は F が L から**離れて楕円を歩きながら**右回転し、戻ってくる（移動を伴う）。Vuelta はその場の右回転 |
| **Vacílala ↔ Right turn** | Vacílala は手を離す（または指先だけ）。2 回転以上しながら移動し、多くは DQN で終わる |
| **Hook turn ↔ Spot turn / Free spin** | Hook turn は回る直前に**脚が後ろで交差**し、小さく速く回る。Spot turn は前へ踏み出して回る |
| **L の背中での持ち替え ↔ L のアンダーアームターン** | 持ち替えでは手が L の腰の後ろで合わさり、腕は頭上へ上がらない。アンダーアームターンでは腕が L の頭上でアーチになる |
| **Neck wrap ↔ Hair comb ↔ Sombrero** | Neck wrap は前腕が首の後ろに止まって保持される。Comb は通過して離れる。Sombrero は両腕が両者の首の後ろに掛かる |
| **Tunnel ↔ CBL with inside turn** | トンネルでは腕のアーチの下を回らずに抜ける。inside turn では回る |
| **On1 ↔ On2** | フォロワーの回転・横断が 5-6-7 なら On1、1-2-3 なら On2。リーダーの左足の前ブレイクが 1（On1）か 6（On2）か（1.5 節） |
| **Inside turn（定義の流派差）** | 名前の対立を避けるため、常に「左回転（CCW）」「右回転（CW）」を併記する |

### 5.1 単眼映像に特有の落とし穴

- **奥行き方向の混同**: スロットがカメラの奥行き方向に伸びていると、CBL の位置の入れ替わりが「手前 ↔ 奥」になる。画面上の左右は変わらないので、頭の大きさ（スケール）と足元の Y 座標で前後を判定する。
- **オクルージョン**: Walk-around、Shadow、Titanic、背中での持ち替えでは、片方が隠れる。隠れる直前と直後のフレームで、位置・持ち手・向きをつないで推定する。
- **腕の左右の取り違え**: 正面から撮ると、F の右手は画面左側にある。持ち手は「画面左右」ではなく、**本人の右手 / 左手**で書く。
- **1 枚の静止画で判断しない**: ホールドや回転方向は、連続 3 フレーム以上で確認する。
