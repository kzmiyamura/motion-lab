カレントディレクトリにサルサペア動画から抜き出した静止画（`anchor_*.jpg`、ファイル名に秒数入り）があります。

手前で踊っているペア（2人）について、**リーダー（通常は男性役。リードしている側）が画面の左右どちらにいるか**を判定してください。

- 背景の見学者・鏡の映り込みは無視する
- 2人が最もはっきり写っている画像を1枚選び、その画像での判定を答える
- 服装・体格・リードの姿勢（手を差し出す・回す側）を根拠にする

**出力は次の1行のJSONのみ**（説明文・コードブロック不要）:

{"t": <選んだ画像の秒数>, "leaderSide": "left" または "right", "leaderLook": "リーダーの見た目の一言（例: グレーシャツの男性）"}

2人が写っている画像が1枚も無い場合のみ: {"t": null, "leaderSide": null, "leaderLook": null}
